# Política de segurança

Não abra issues públicas contendo:

- sessão ou token do WhatsApp;
- perfil do Chromium;
- senha SIP;
- IP público, regra de firewall ou credencial;
- número de telefone, conteúdo de conversa ou outro dado pessoal;
- logs completos de produção.

Antes de anexar logs, substitua identificadores por valores fictícios e preserve apenas estados, timestamps relativos e códigos de erro.

O projeto automatiza um cliente web e depende de APIs internas que podem mudar. Use apenas contas de laboratório durante o desenvolvimento e avalie termos aplicáveis antes de qualquer implantação.
